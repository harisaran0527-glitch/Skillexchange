# SkillSwap - Frontend (Vite + React + TypeScript)

This is the frontend scaffold for SkillSwap — a student skill exchange platform.

Tech stack:
- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

Quick start:
1. cd frontend
2. npm install
3. npm run dev

Notes:
- Uses mock JSON in src/services/mockData.ts for now.
- Next steps: add reusable UI components, detailed pages, skeletons, empty states, accessibility improvements, unit tests.
